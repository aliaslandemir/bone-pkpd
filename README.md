# Bone Model PK/PD

A Python project for learning pharmacokinetic and pharmacodynamic (PK/PD) modelling, with a focus on bone regeneration and tissue engineering.

Starting with simple drug concentration–time models, the project aims extend to drug effects on bone cells, mineralization, and biomaterial-based delivery.

### Scope
- Basic PK models: IV, SC, and oral administration
- Drug absorption, distribution, and elimination
- PK parameters: clearance, half-life, AUC, and volume of distribution
- PK/PD relationships for bone-related drugs
- Drug release from hydrogels and other biomaterials

Requires basic modules.
